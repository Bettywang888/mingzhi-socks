Who pays when the size is wrong?

In B2B socks almost nothing gets returned. Not because the fit is always right, but because the size was approved before the order ran, and approval moves the risk. Knowing where that line sits is worth more than any size chart.

The pattern that causes trouble is a buyer who takes a stock range — S/M/L, or 39-42 / 43-46 — assumes it suits their market, and finds out at the end of the first season that one size is dead stock and another sold out twice. Nothing is returned. The cost appears as inventory, not as a credit note.

So the useful question is not "what is your size chart" but "what is this chart measured against". Three different things get called a sock size.

Shoe size, which is what a retail sock label normally carries. It is convenient and it is a poor proxy: shoe size encodes length, and nothing about width, instep height or ankle.

Foot length in centimetres, which is what a knitting programme actually needs. This is the number that belongs in a specification.

Finished sock dimensions — cuff circumference, leg length, foot length, heel depth. This is what a factory measures on the table, and the only version that can be inspected against.

A chart that gives only the first, and a factory that works only from the second, will produce socks that are technically to spec and wrong on the foot.

Three things reduce the risk, and none of them is a bigger return allowance.

Approve on a foot, not on a table. Ask for the sample to be worn by someone in the target size, in the target shoe, for a full session. A sock that measures correctly and rides down inside a boot is still a wrong sock.

Fix the size split before production. The mix of sizes in a 600-pair order is a decision, and it is far cheaper to change on paper. Ask for the split to be written into the order confirmation rather than agreed in a message.

Ask what happens at the boundary. Every range overlaps — 43-46 and 39-42 both claim 43. Decide once which size the boundary goes into, and record it.

What is genuinely the supplier's problem is the fourth case: socks that do not match the approved sample. That is not a sizing question, it is a defect, and it should be judged against the sample. Get the sample signed and dated and there is nothing to argue about.
